# NeptuneTime — Minecraft server website

## Запуск
Открой `index.html` в браузере или загрузи всю папку на статический хостинг.

## Магазин и корзина
- Вместо страницы доната теперь `shop.html` с кейсами, привилегиями и Neptune Coins.
- Корзина работает в браузере: добавление товаров, изменение количества, удаление, очистка и подсчёт суммы.
- Содержимое сохраняется в `localStorage` этого браузера.
- Оплата пока демонстрационная: подключи платёжный шлюз, серверный API и выдачу товаров после подтверждения платежа.

## Перед запуском
- Замени демонстрационный IP `play.neptunetime.ru` на реальный.
- Настрой ассортимент, цены, описание кейсов и привилегий.
- Замени демонстрационные платёжные ссылки и подключи безопасную серверную обработку заказов.
- Проверь правила, версию и характеристики сервера.
- Логотип из сообщения находится в `assets/logo.jpg`.
